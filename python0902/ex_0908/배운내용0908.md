# FastAPI 학습 정리

## 1. FastAPI란?

FastAPI는 Python으로 웹 API를 빠르게 만들 수 있는 프레임워크임.

- Python 타입 힌트를 이용해 요청 데이터를 자동으로 검증함.
- 비동기 함수(`async def`)를 지원함.
- API를 만들면 문서 페이지가 자동으로 생성됨.
- `uvicorn`과 함께 실행하는 경우가 많음.

## 2. 설치 및 실행

```bash
pip install "fastapi[standard]"
```

`main.py`가 있는 폴더에서 다음 명령으로 서버 실행함.

```bash
fastapi dev main.py
# 또는
uvicorn main:app --reload
```

- main: 파일명 (main.py에서 .py 제외)
- app: 코드 내부의 FastAPI 인스턴스 변수명 (app = FastAPI())
- --reload: 코드가 수정될 때마다 서버를 자동으로 재시작 (개발용)
- --host 0.0.0.0: 외부 접속 허용
- --port 8000: 포트 번호 변경 (기본값: 8000)
실행 후 기본 주소는 `http://127.0.0.1:8000`임.

자동 API 문서는 다음 주소에서 확인 가능함.

- Swagger UI: `http://127.0.0.1:8000/docs`

## 3. 기본 구조

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}
```

`@app.get("/")`는 HTTP GET 요청이 `/` 주소로 들어왔을 때 바로 아래 함수를 실행한다는 뜻임.

함수가 dictionary를 반환하면 FastAPI가 JSON 형식으로 변환해 응답함.

```json
{"Hello": "World"}
```

## 4. 경로 매개변수(Path Parameter)

URL의 `{}` 부분은 경로 매개변수임.

```python
@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

예를 들어 다음과 같이 요청 가능함.

```text
http://127.0.0.1:8000/items/3
http://127.0.0.1:8000/items/3?q=book
```

`item_id: int`라고 타입을 지정했기 때문에 `item_id`는 정수로 변환됨. 정수가 아닌 값이 들어오면 FastAPI가 오류 반환함.

`q: str | None = None`은 `q`가 문자열이거나 값이 없을 수 있다는 의미임. 기본값이 `None`이므로 `q`는 선택 사항임.

## 5. 경로 순서의 중요성

```python
@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}

@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

`/users/me`를 `/users/{user_id}`보다 먼저 선언함. 그렇지 않으면 `me`가 일반적인 `user_id` 값으로 해석될 수 있음.

따라서 고정된 경로는 동적 경로보다 먼저 작성하는 것이 안전함.

## 6. Enum을 이용한 경로 값 제한

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {
            "model_name": model_name,
            "message": "키 요청: Deep Learning FTW!"
        }

    if model_name.value == "lenet":
        return {
            "model_name": model_name,
            "message": "값 요청: LeCNN all the images"
        }

    return {
        "model_name": model_name,
        "message": "Have some residuals"
    }
```

허용되는 모델 이름은 `alexnet`, `resnet`, `lenet`뿐임.

- `model_name is ModelName.alexnet`: Enum 멤버 자체를 비교함.
- `model_name.value == "lenet"`: Enum 멤버가 가지고 있는 실제 문자열 값을 비교함.
- `resnet`은 위 조건에 해당하지 않으므로 마지막 응답 반환함.

예시:

```text
/models/alexnet  -> 키 요청: Deep Learning FTW!
/models/lenet    -> 값 요청: LeCNN all the images
/models/resnet   -> Have some residuals
```

Enum에 없는 값을 요청하면 FastAPI가 입력값 검증 오류 반환함.

## 7. 쿼리 매개변수(Query Parameter)

```python
fake_items_db = [
    {"item_name": "Foo"},
    {"item_name": "Bar"},
    {"item_name": "Baz"},
]

@app.get("/items2/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip: skip + limit]
```

경로에 `{}`가 없고 함수 매개변수로 선언된 값은 쿼리 매개변수로 처리됨.

```text
/items2/
/items2/?skip=1&limit=1
```

- `skip`: 앞에서 몇 개를 건너뛸지 나타냄. 기본값은 `0`임.
- `limit`: 최대 몇 개를 가져올지 나타냄. 기본값은 `10`임.
- `fake_items_db[skip: skip + limit]`: 리스트의 `skip` 위치부터 `skip + limit` 직전까지 가져옴.

예를 들어 `skip=1&limit=1`이면 두 번째 항목인 `Bar` 반환됨.

## 8. 경로 매개변수와 쿼리 매개변수 함께 사용하기

```python
@app.get("/items2/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

요청 예시는 다음과 같음.

```text
/items2/hello
/items2/hello?q=fastapi
```

`item_id`는 URL 경로에서 가져오고, `q`는 `?` 뒤의 쿼리 문자열에서 가져옴.

## 9. `def`와 `async def`

두 방식 모두 FastAPI에서 사용 가능함.

```python
def read_root():
    ...

async def read_user():
    ...
```

파일·데이터베이스·외부 API처럼 `await`가 필요한 비동기 작업을 사용할 때는 `async def` 사용함. 단순한 함수는 일반적인 `def`로 작성해도 됨.

## 핵심 정리

1. `app = FastAPI()`로 FastAPI 애플리케이션 생성함.
2. `@app.get("주소")`와 함수를 연결해 API 생성함.
3. `{item_id}`는 경로 매개변수이고, 함수 매개변수만 선언한 값은 쿼리 매개변수임.
4. 타입 힌트가 입력값 검증과 자동 변환을 담당함.
5. Enum을 사용하면 허용할 경로 값을 제한할 수 있음.
6. `uvicorn main:app --reload`로 개발 서버 실행함.
