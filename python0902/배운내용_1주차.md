## 1. 파이썬 기본 문법

### 1.1 주석, 변수, 출력

- `#` 뒤의 내용은 실행되지 않는 주석임.
- 변수는 값을 저장하고, `print()`는 값을 화면에 출력함.
- 문자열은 따옴표로 감싸고 숫자는 따옴표 없이 작성함.
- `type()`은 자료형, `len()`은 문자열이나 컬렉션의 길이를 확인함.
- `print()`의 `sep` 인자로 여러 값 사이의 구분자를 지정할 수 있음.

```python
title = "AI 서비스 백엔드 프로그래머 실무"
hours = 8

print(title, hours, sep=", 시간:")
print(type(hours))
print(len(title))
```

### 1.2 문자열과 f-string

문자열은 인덱싱과 슬라이싱으로 일부를 가져올 수 있음. 슬라이싱은 시작 위치를 포함하고 끝 위치는 포함하지 않음.

```python
text = "The best things in life are free!"

print(text[2:5])
print(text[:5])
print(text[5:])
print(text[-5:])
print("free" in text)  # True
```

주요 문자열 메서드는 다음과 같음.

| 메서드 | 기능 |
| --- | --- |
| `upper()`, `lower()` | 대문자·소문자로 변환 |
| `strip()` | 양쪽 공백 제거 |
| `lstrip()`, `rstrip()` | 왼쪽·오른쪽 공백 제거 |
| `replace(a, b)` | 문자열 일부 교체 |
| `split(sep)` | 구분자를 기준으로 나누어 리스트 생성 |
| `center(width, fillchar)` | 지정한 길이의 가운데에 배치 |
| `isupper()`, `islower()` | 모두 대문자·소문자인지 확인 |
| `maketrans()`, `translate()` | 문자 변환표를 만들어 일괄 치환 |

f-string은 문자열 안에 변수와 서식을 넣을 때 사용함.

```python
age = 28

print(f"나이는 {age}살임")
print(f"나이: {age:.2f}")  # 소수점 둘째 자리까지 표시
```

### 1.3 컬렉션

| 자료형 | 순서 | 변경 | 중복 | 특징 |
| --- | --- | --- | --- | --- |
| `list` | O | O | O | 여러 값을 순서대로 저장 |
| `tuple` | O | X | O | 생성 후 항목 변경 불가 |
| `set` | X | O | X | 중복 제거, 항목 추가·삭제 가능 |
| `dict` | O | O | 키 중복 X | `키: 값` 형태로 저장 |

```python
topics = ["파이썬 기본 문법", "클래스", "예외 처리", "로깅"]
```

#### 딕셔너리

```python
student = {

print(student.keys())    # 키
```

### 1.4 조건문

```python
a = 33
b = 33

if a > b:
    print("a > b")
elif a == b:
    print("a == b")
else:
    print("a < b")
```

간단한 조건은 조건 표현식으로 한 줄에 작성할 수 있음. 이는 `lambda`가 아니라 **조건 표현식(삼항 표현식)**임.

```python
result = "a가 더 큼" if a > b else "b가 a보다 크거나 같음"
```

`match`는 하나의 값을 여러 경우와 비교할 때 사용함. `_`는 어떤 앞선 경우에도 해당하지 않을 때 실행되는 기본 패턴임.

```python
day = 2

match day:
    case 1 | 2 | 3 | 4 | 5:
        print("weekday")
    case 6 | 7:
        print("weekend")
    case _:
        print("invalid day")
```

### 1.5 반복문과 `range()`

`for`문은 컬렉션의 값을 하나씩 꺼내 반복하고, `while`문은 조건이 참인 동안 반복함. `while`문에는 반드시 종료 조건이 필요함.

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
    if fruit == "banana":
        break
```

```python
i = 0

while i < 6:
    i += 1
    print(i)
else:
    print("반복 조건이 거짓이 되어 종료됨")
```

`range(start, stop, step)`은 `start`부터 `stop` 직전까지 `step` 간격의 정수를 만듦.

```python
for number in range(2, 20, 5):
    print(number)  # 2, 7, 12, 17
```

### 1.6 함수와 왈러스 연산자

함수는 반복 사용할 코드를 `def`로 묶고, `return`으로 결과를 호출한 곳에 반환함.

```python
def add_one_hundred(number):
    return number + 100

print(add_one_hundred(5))  # 105
```

`:=`는 값을 변수에 대입하면서 같은 표현식 안에서 그 값을 사용하는 **대입 표현식(왈러스 연산자)**임.

```python
if (length := len("hello")) > 3:
    print(length)  # 5
```

### 1.7 클래스와 객체

클래스는 객체를 만들기 위한 설계도임. `__init__()`은 객체 생성 시 실행되는 초기화 메서드이고 `self`는 현재 객체를 가리킴.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"Hello, {self.name}")


person = Person("Hyerim", 28)
person.greet()
```

- `person`: 객체(인스턴스)
- `name`, `age`: 속성
- `greet()`: 메서드

## 4. Streamlit

Streamlit은 Python 코드로 입력창, 버튼, 표, 차트가 있는 간단한 웹 화면을 만들 수 있는 라이브러리임. 이 과정에서는 백엔드 학습에 집중하면서 프런트엔드 화면을 빠르게 구성하는 용도로 사용함.

### 4.1 기본 화면과 실행

```python
import streamlit as st

st.title("제목")
st.write("안녕하세요")
prompt = st.chat_input("메시지를 입력하세요")
submit = st.button("JOIN", type="primary")
```

```bash
streamlit run app.py
```

`st.empty()`는 나중에 교체하거나 비울 수 있는 빈 화면 영역을 만듦. `st.empty().container()`를 사용하면 그 영역 안에 여러 요소를 배치할 수 있음.

### 4.2 세션 상태와 페이지 이동

`st.session_state`는 화면이 다시 실행되어도 유지해야 할 사용자 상태를 저장함.

```python
if "purpose" not in st.session_state:
    st.session_state.purpose = None

purpose = st.selectbox("Choose your purpose", ["Study", "Work"])

if st.button("Go"):
    st.session_state.purpose = purpose
    st.rerun()
```

- `st.Page()`로 페이지를 등록함.
- `st.navigation()`으로 페이지 메뉴를 구성함.
- `st.rerun()`으로 현재 스크립트를 다시 실행함.
- 로그아웃 시 관련 세션 값을 초기화한 뒤 다시 실행함.

## 5. Pydantic

Pydantic은 타입 힌트를 바탕으로 외부 입력값을 검증하고, 변환 가능한 값은 선언한 타입으로 변환함. API 요청과 비즈니스 로직 사이에 두면 검증된 데이터만 내부 로직에 전달할 수 있음.

```text
API 요청 → Pydantic 검증·변환 → 비즈니스 로직 → 직렬화·응답
```

### 5.1 `BaseModel`과 타입 변환

```python
from pydantic import BaseModel, ValidationError


class User(BaseModel):
    name: str
    age: int
    email: str


try:
    user = User(name="Hyerim", age="28", email="user@example.com")
    print(user.age, type(user.age))  # 28 <class 'int'>
except ValidationError as error:
    print(error.errors())
```

`email: str`은 문자열 여부만 검사함. 이메일 형식까지 검증하려면 `EmailStr`과 같은 전용 타입을 사용해야 함.

### 5.2 제약 조건과 선택 필드

```python
from pydantic import BaseModel, Field


class Address(BaseModel):
    city: str
    zip_code: str


class User(BaseModel):
    name: str = Field(min_length=2, max_length=20)
    age: int = Field(ge=0, le=150)
    address: Address
    nickname: str | None = None
```

- `ge`, `le`: 최솟값·최댓값을 포함한 범위 제한
- `min_length`, `max_length`: 문자열 길이 제한
- `str | None`: 문자열 또는 `None` 허용
- 기본값 `= None`까지 있어야 필드 입력을 생략할 수 있음.
- 다른 `BaseModel`을 필드 타입으로 사용하면 중첩 JSON도 계층적으로 검증함.
- `Literal`이나 `Annotated`를 이용해 허용값과 더 세부적인 조건을 선언할 수 있음.

### 5.3 직렬화

| 메서드 | 반환 타입 | 용도 |
| --- | --- | --- |
| `model_dump()` | Python `dict` | Python 내부 처리와 데이터 수정 |
| `model_dump_json()` | JSON 문자열 | API 전송이나 JSON 파일 저장 |

```python
data = user.model_dump(exclude_unset=True)
json_text = user.model_dump_json(exclude_defaults=True)
```

- `exclude_unset=True`: 객체 생성 시 직접 입력하지 않은 필드 제외
- `exclude_defaults=True`: 현재 값이 기본값과 같은 필드 제외
- `exclude={"field_name"}`: 지정한 필드 제외
- `mode="json"`: `datetime` 등을 JSON에 맞는 값으로 변환

## 6. FastAPI

FastAPI는 Python으로 웹 API를 만드는 프레임워크임. 타입 힌트를 이용한 입력값 검증, 비동기 함수, 자동 API 문서를 지원하며 보통 Uvicorn으로 실행함.

### 6.1 설치와 실행

```bash
pip install "fastapi[standard]"
fastapi dev main.py

# 또는
uvicorn main:app --reload
```

- `main`: `main.py`에서 확장자를 제외한 모듈명
- `app`: 파일 안의 `FastAPI()` 인스턴스 변수명
- `--reload`: 코드 변경 시 개발 서버 자동 재시작
- 기본 서버 주소: `http://127.0.0.1:8000`
- Swagger UI: `http://127.0.0.1:8000/docs`

### 6.2 기본 API

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def read_root():
    return {"hello": "world"}
```

함수가 딕셔너리를 반환하면 FastAPI가 JSON 응답으로 변환함.

### 6.3 경로 매개변수와 쿼리 매개변수

```python
@app.get("/items/{item_id}")
def read_item(item_id: int, query: str | None = None):
    return {"item_id": item_id, "query": query}
```

- `item_id`: URL 경로의 `{item_id}`에서 받는 경로 매개변수
- `query`: `?query=book` 형태로 받는 쿼리 매개변수
- 타입 힌트에 따라 값을 검증하고 가능한 경우 자동 변환함.
- 기본값이 있으면 선택 매개변수로 사용할 수 있음.

고정 경로는 동적 경로보다 먼저 선언하는 것이 안전함.

```python
@app.get("/users/me")
def read_current_user():
    return {"user_id": "current user"}


@app.get("/users/{user_id}")
def read_user(user_id: str):
    return {"user_id": user_id}
```

`Enum`을 매개변수 타입으로 사용하면 URL에서 허용할 값을 제한할 수 있음.

### 6.4 `def`와 `async def`

두 방식 모두 사용할 수 있음. 파일, 데이터베이스, 외부 API 호출처럼 `await`가 필요한 비동기 작업이 있으면 `async def`를 사용하고 단순한 함수는 `def`로 작성해도 됨.

### 6.5 CRUD

| 기능 | 의미 | HTTP 메서드 | FastAPI 데코레이터 예시 |
| --- | --- | --- | --- |
| Create | 생성 | `POST` | `@app.post("/games/")` |
| Read | 조회 | `GET` | `@app.get("/games/")` |
| Update | 수정 | `PUT` | `@app.put("/games/{game_id}")` |
| Delete | 삭제 | `DELETE` | `@app.delete("/games/{game_id}")` |

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()


class Game(BaseModel):
    name: str
    price: int


games_db = {
    1: {"name": "MapleStory", "price": 0},
    2: {"name": "Dave the Diver", "price": 25000},
}


@app.get("/games/")
def read_games():
    return games_db


@app.post("/games/")
def create_game(game: Game):
    new_id = max(games_db, default=0) + 1
    games_db[new_id] = game.model_dump()
    return {"game_id": new_id, "game": games_db[new_id]}


@app.put("/games/{game_id}")
def update_game(game_id: int, game: Game):
    if game_id not in games_db:
        raise HTTPException(status_code=404, detail="게임을 찾을 수 없습니다.")

    games_db[game_id] = game.model_dump()
    return {"game_id": game_id, "game": games_db[game_id]}


@app.delete("/games/{game_id}")
def delete_game(game_id: int):
    if game_id not in games_db:
        raise HTTPException(status_code=404, detail="게임을 찾을 수 없습니다.")

    deleted_game = games_db.pop(game_id)
    return {"game_id": game_id, "deleted_game": deleted_game}
```

학습용 딕셔너리 DB는 서버가 종료되면 변경 내용이 사라짐. `HTTPException`은 `return`이 아니라 `raise`로 발생시키며, `model_dump()`는 Pydantic 객체를 저장 가능한 딕셔너리로 바꿀 때 사용함.

## 7. OpenAI API와 API 키 관리


## 8. LangChain과 RAG

### 8.1 LangChain

LangChain은 LLM, 프롬프트, 대화 기록, 문서 검색, 외부 도구와 여러 작업 단계를 연결하기 위한 프레임워크임.

| 구성 요소 | 역할 |
| --- | --- |
| Model | LLM 연결 |
| Prompt | 모델에 전달할 입력 형식 관리 |
| Chain | 여러 작업의 실행 순서 연결 |
| Memory | 이전 대화나 실행 결과 관리 |
| Retriever | 관련 문서 검색 |
| Agent | 상황에 따라 도구와 작업 선택 |

한 번의 단순한 모델 호출만 필요하면 OpenAI SDK를 직접 사용하는 편이 간단할 수 있고, 여러 구성 요소를 조합하거나 교체해야 하면 LangChain이 유용함.

### 8.2 `ChatOpenAI` 호출

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="사용할_모델명",
    temperature=0.1,
)

response = llm.invoke("대한민국의 수도는?")

print(response.content)
print(response.response_metadata)
```

- `invoke()` 결과는 단순 문자열이 아니라 메시지 객체임.
- 답변은 `response.content`, 토큰과 모델 정보 등은 메타데이터에서 확인함.
- `temperature`, `logprobs`, 토큰 제한 매개변수의 지원 여부와 이름은 모델 및 호출 API에 따라 다를 수 있음.
- `logprobs`가 필요하면 해당 기능을 지원하는 모델인지 먼저 확인함. 단순 토큰 사용량 확인에는 `logprobs`가 필요하지 않음.

### 8.3 스트리밍

`invoke()`는 답변이 완성된 후 반환하고, `stream()`은 생성되는 내용을 작은 조각으로 받아 바로 표시함.

```python
question = "간단한 파이썬 공부 계획을 알려줘"
final_answer = ""

for chunk in llm.stream(question):
    print(chunk.content, end="", flush=True)
    final_answer += chunk.content
```

스트림은 한 번 순회하면 소비됨. 나중에 다시 사용할 내용은 첫 번째 반복문에서 문자열에 함께 저장해야 함. 스트리밍은 체감 응답 속도를 높이지만 같은 내용을 생성할 때 토큰을 자동으로 줄여 주지는 않음.

### 8.4 Jupyter Notebook 활용

Notebook은 셀 단위 실행과 객체 상태 유지가 가능하여 초기화 코드와 질의 코드를 나누어 실험하기 좋음. 다만 Notebook 자체가 호출당 토큰을 줄여 주는 것은 아니므로 API 호출 셀을 불필요하게 반복 실행하지 않아야 함.

### 8.5 RAG

RAG(Retrieval-Augmented Generation)는 질문과 관련된 외부 문서를 검색한 뒤, 검색 결과를 LLM에 함께 전달해 답변을 만드는 검색 증강 생성 방식임.

```text
문서 로드
  → 텍스트 분할
  → 임베딩
  → 벡터 스토어 저장
  → 관련 문서 검색(Retriever)
  → 질문과 검색 문맥으로 프롬프트 구성
  → LLM 답변 생성
  → 전체 흐름을 Chain으로 연결
```

| 단계 | 역할 |
| --- | --- |
| 문서 로드 | PDF, 웹페이지, 데이터베이스 등의 문서 읽기 |
| 텍스트 분할 | 긴 문서를 검색하기 적당한 청크로 나누기 |
| 임베딩 | 텍스트의 의미를 벡터로 변환 |
| 벡터 스토어 | 벡터와 원문 저장 |
| 리트리버 | 질문과 관련성이 높은 청크 검색 |
| 프롬프트 | 질문과 검색 문맥을 LLM 입력 형식으로 구성 |
| LLM | 제공된 문맥을 바탕으로 답변 생성 |
| 체인 | 각 구성 요소의 실행 순서 연결 |

RAG는 모델이 학습하지 않은 최신 정보나 내부 문서를 활용하고 답변 근거를 제시하는 데 유리함. 반대로 문서 분할이나 검색 결과의 품질이 낮으면 최종 답변의 품질도 낮아질 수 있음.

## 9. 실무 메모

- API 명세는 Swagger UI뿐 아니라 별도 문서로도 관리함.
- Swagger UI를 협업용 문서로 내보낼 때 초기값과 필수값을 명확히 표시함.
- 배포 구조에서는 Docker Compose 같은 컨테이너 구성도 함께 학습함.
- AI를 활용하기 전에 먼저 전체 아키텍처와 핵심 검증 로직을 직접 설계함.
- 작은 검증 기능을 완성한 뒤 AI를 이용해 확장하고, 기능 구현 후에는 예외 처리·구조·가독성을 고도화함.

## 10. 전체 핵심 정리

1. Python의 문자열, 컬렉션, 조건문, 반복문, 함수, 클래스가 모든 실습의 기반임.
2. 가상환경과 `requirements.txt`로 프로젝트별 패키지를 재현 가능하게 관리함.
3. NumPy·pandas는 데이터를 처리하고 Matplotlib은 결과를 시각화함.
4. Streamlit은 Python만으로 빠르게 웹 화면을 구성하고 세션 상태를 관리함.
5. Pydantic은 API 입력값을 검증·변환하고 응답 가능한 형태로 직렬화함.
6. FastAPI는 경로와 HTTP 메서드를 함수에 연결하며 Pydantic과 함께 안전한 CRUD API를 구성함.
7. API 키는 코드와 저장소에서 분리하고 노출 시 즉시 폐기함.
8. LangChain은 LLM 관련 구성 요소를 연결하고, RAG는 외부 문서 검색 결과를 바탕으로 답변의 근거와 활용 범위를 확장함.
