# 파이썬 학습 내용

## 1. 주석과 출력

`#` 뒤에 작성한 내용은 주석임. 주석은 실행되지 않으며 코드 설명이나 임시로 실행하지 않을 코드를 표시할 때 사용함.

`print()` 함수는 화면에 값을 출력하고, 변수는 데이터를 저장함.

```python
title = "AI 서비스 백엔드 프로그래머 실무"
time = 8

print(title)
print(time)
```

문자열은 따옴표로 감싸고, 숫자는 따옴표 없이 작성함. `print()`에 `sep`를 사용하면 여러 값 사이의 구분자를 지정할 수 있음.

```python
print("파이썬 기본 문법", 8, sep=", 시간:")
```

실행 결과는 `파이썬 기본 문법, 시간:8`임.

## 2. 리스트와 반복문

리스트는 여러 값을 하나로 묶어 저장하는 자료형임.

```python
txtlist = ["파이썬 기본 문법", "클래스", "데코레이터", "예외 처리", "로깅"]
```

`for`문은 리스트의 항목을 하나씩 꺼내 반복 실행함.

```python
for x in txtlist:
    print(x, 8, sep=", 시간:")
```

반복할 코드는 들여쓰기해야 함. 반복할 때마다 `x`에는 리스트의 항목이 하나씩 저장됨.

## 3. 함수

함수는 특정 작업을 수행하는 코드를 묶어 재사용하는 기능임. `def`로 선언하고, 괄호 안에 매개변수를 작성함. `return`은 결과를 함수를 호출한 곳으로 돌려줌.

```python
def f1(a):
    return a + 100

print(f1(5))
```

`f1(5)`를 호출하면 `a`에 `5`가 전달되고, `105`가 반환되어 출력됨.

## 4. 사칙연산 함수

`test.py`에서는 연산별로 함수를 만듦.

```python
def f1(a):
    return a + 100      # 덧셈

def f2(b):
    return b - 100      # 뺄셈

def f3(c):
    return c * 100      # 곱셈

def f4(d):
    return d / 100      # 나눗셈
```

다음 코드를 실행하면 결과는 각각 `105`, `-95`, `500`, `0.05`임.

```python
print(f1(5))
print(f2(5))
print(f3(5))
print(f4(5))
```

파이썬에서 `/`는 나눗셈 결과를 실수로 반환함.

## 5. `pip install` 사용법

`pip`는 파이썬 패키지를 설치하고 관리하는 도구임. 다음 명령으로 패키지를 설치함.

```bash
python -m pip install 패키지이름
```

예시:

```bash
python -m pip install requests
python -m pip install requests flask
```

설치된 패키지 목록을 저장하고, 저장된 목록을 다시 설치할 수도 있음.

```bash
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```

## 6. 가상환경 만들기와 사용하기

가상환경은 프로젝트마다 독립된 파이썬 환경을 만드는 기능임. 프로젝트별 패키지 버전이 달라도 서로 충돌하지 않게 관리할 수 있음.
가상환경이 Git에 업로드되지 않도록 .gitignore에 추가해주기!

### 가상환경 생성

프로젝트 폴더에서 다음 명령을 실행함.

```bash
python -m venv .name
```

`.name`은 원하는 가상환경 폴더 이름으로 바꿔 쓰면 됨. 보통 `.venv`를 사용함.

```bash
python -m venv .venv
```

### Windows 명령 프롬프트에서 활성화
생성된 가상환경의 Scripts의 activate.bat 파일의 상대경로를 복사하여 넣는다. 

```cmd
.venv\Scripts\activate.bat
```

활성화되면 터미널 앞에 `(.venv)`가 표시됨. 이후 설치하는 패키지는 해당 가상환경에 설치됨.


### 가상환경 종료
생성된 가상환경의 Scripts의 deactivate.bat 파일의 상대경로를 복사하여 넣는다. 

```bash
deactivate
```

## 핵심 정리

- `#`은 주석을 작성하는 기호임.
- `print()`는 값을 출력하고, `sep`로 값 사이의 구분자를 정할 수 있음.
- 리스트는 여러 데이터를 저장하며, `for`문으로 항목을 반복 처리할 수 있음.
- 함수는 `def`로 만들고 `return`으로 결과를 반환함.
- `pip install`은 파이썬 패키지를 설치하는 명령임.
- `python -m venv .name`은 프로젝트용 가상환경을 생성하는 명령임.
