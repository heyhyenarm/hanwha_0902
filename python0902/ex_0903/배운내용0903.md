## 1. 파이썬 기본 문법

```python
x = 5
y = "John"
print(type(x))      # 자료형 확인
print(len(y))       # 문자열 길이
```

문자열은 `for`문으로 한 글자씩 반복할 수 있음. `in`을 사용하면 특정 문자열이 포함되어 있는지 확인할 수 있음.

```python
txt = "The best things in life are free!"

for char in txt:
    print(char)

print("free" in txt)    # True
```

문자열의 일부는 슬라이싱으로 가져옴. 시작 위치는 포함되고 끝 위치는 포함되지 않음.

```python
print(txt[2:5])
print(txt[:5])
print(txt[5:])
print(txt[-5:])
```

자주 사용하는 문자열 메서드는 다음과 같음.

```python
txt.upper()                # 대문자
txt.lower()                # 소문자
txt.strip()                # 양쪽 공백 제거
txt.replace("T", "S")      # 문자열 교체
txt.split(" ")             # 구분자로 나누어 리스트 생성
```

## 2. 클래스와 객체

클래스는 객체를 만들기 위한 설계도임. `__init__()`은 객체가 생성될 때 실행되는 초기화 메서드이며, `self`는 현재 객체를 의미함.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print("Hello", self.name)

    def display_info(self):
        print(f"{self.name} {self.age}")

p1 = Person("남혜림", 28)
p1.greet()
p1.display_info()
```

`Person`으로 만든 `p1`은 객체이고, `name`과 `age`는 속성, `greet()`와 `display_info()`는 메서드임.

## 3. Streamlit으로 웹 화면 만들기

Streamlit은 파이썬 코드로 간단한 웹 화면을 만드는 라이브러리임.

```python
import streamlit as st

st.write("안녕하세요")
st.title("제목")
```

입력과 화면 갱신에는 다음 기능을 사용할 수 있음.

```python
selected = st.feedback("faces")
prompt = st.chat_input("메시지를 입력하세요")
submit = st.button("JOIN", type="primary")
placeholder = st.empty()
```

`st.empty()`로 만든 공간은 `placeholder.empty()`로 비울 수 있음. `st.empty().container()`를 사용하면 해당 공간 안에 여러 화면 요소를 배치할 수 있음.

Streamlit 파일 실행:

```bash
streamlit run test.py
```

## 4. pandas와 NumPy

NumPy는 배열과 수치 계산을, pandas는 표 형태의 데이터를 다루는 라이브러리임.

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "first column": [1, 2, 3, 4],
    "second column": [10, 20, 30, 40]
})

data = np.random.randn(10, 20)
df_random = pd.DataFrame(data)
```

`np.random.randn()`은 정규분포를 따르는 임의의 숫자를 만들고, `pd.DataFrame()`은 데이터를 표 형식으로 변환함.

Streamlit에서는 DataFrame을 다음처럼 화면에 출력할 수 있음.

```python
st.dataframe(df)
st.dataframe(df_random)
```

## 5. Matplotlib 그래프

Matplotlib은 데이터를 그래프로 표현하는 라이브러리임.

```python
import matplotlib.pyplot as plt
import numpy as np

ypoints = np.array([3, 5, 9, 1])
plt.plot(ypoints, "*:c", ms=15, mec="m", mfc="m")
plt.show()
```

`plot()`의 옵션으로 선 모양과 색상, 마커 크기 등을 지정할 수 있고 `show()`로 그래프를 표시함.
