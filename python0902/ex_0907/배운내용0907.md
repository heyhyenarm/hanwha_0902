# pydantic
data로 다른 형식이 들어와도 자동 형변환 기능이 있음.

## Serialization 직렬화
Pydantic 객체를 다른 형식으로 변환함. 
주로 API 응답이나 JSON 저장에 사용됨. 
입력된 값을 Pydantic 객체로 자동 변환 -> model_dump()로 Pydantic 객체를 Python Dictionary로 변환. 
ex) m.model_dump(exclude={'where'}, mode='json')
-> exclude_unset=True는 사용자가 입력하지 않은 기본값 제외.
-> exclude는 내부에 넣은 필드 where 제외.
-> mode='json'은 값을 JSON에 맞는 문자열로 변환. 내부 사용. 
ex) model_dump_json()
-> 객체를 바로 JSON 문자열로 변환. API 전송이나 JSON 파일 저장에 적합. 

# tuple
하나의 변수에 여러 항목을 저장. 
순서가 정해져있음. 변경X. 중복 값 허용. 

# 파이썬 컬렉션 비교
* list: 순서O, 변경O, 중복O
* tuple: 순서O, 변경X, 중복O
* set: 순서X, 변경X, 중복X -> 아이템 추가/삭제는 가능
* dictionary: 순서O, 변경O, 중복X
