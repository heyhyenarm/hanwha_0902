## 1. 복습

- Python: 데이터를 다루는 문법이 중요함.
- Pandas: 표 형태의 데이터를 처리하고 분석할 때 사용함.
- Matplotlib: 데이터를 그래프로 시각화할 때 사용함.
- Pydantic: 입력 데이터의 형식과 타입을 검증하고 필요한 경우 변환함.
- FastAPI: 특정 경로로 요청이 들어왔을 때 어떤 데이터를 응답할지 API로 설계함.
- Streamlit: Python으로 간단한 웹 화면을 구현할 때 사용함.

## 2. CRUD란?

CRUD는 데이터를 생성하고 조회하고 수정하고 삭제하는 네 가지 기본 기능을 뜻함.

| 기능 | 의미 | HTTP 메서드 |
| --- | --- | --- |
| Create | 데이터 생성 | `POST` |
| Read | 데이터 조회 | `GET` |
| Update | 데이터 수정 | `PUT` |
| Delete | 데이터 삭제 | `DELETE` |

FastAPI에서는 다음과 같은 데코레이터로 각 기능의 API를 만들 수 있음.

```python
@app.get("/games/")
@app.post("/games/")
@app.put("/games/{game_id}")
@app.delete("/games/{game_id}")
```

## 3. 딕셔너리를 임시 데이터베이스로 사용하기

```python
games_db = {
    1: {"name": "maplestory", "price": 0},
    2: {"name": "DavetheDiver", "price": 25000},
}
```

파이썬 딕셔너리를 사용해 게임 데이터를 메모리에 저장함.

- 키는 게임 ID임.
- 값은 게임 이름과 가격을 담은 딕셔너리임.
- 서버가 종료되면 메모리에 저장된 변경 사항이 사라짐.


## 4. POST로 데이터 생성하기

```python
@app.post("/games/")
async def create_game(game: Game):
    new_id = len(games_db) + 1
    games_db[new_id] = game.model_dump()
    return {
        "message": "post game success.",
        "game_name": game.name,
        "game_price": game.price,
        "in games_db": games_db[new_id]
    }
```

`game: Game`으로 요청 본문을 전달받음.

- Pydantic이 요청 데이터를 `Game` 모델에 맞게 검증함.
- `game.name`, `game.price`로 각 값에 접근함.
- `model_dump()`를 사용해 Pydantic 모델을 딕셔너리로 변환함.
- 변환한 데이터를 `games_db`에 추가함.

별도의 프론트 화면이 없어도 `http://127.0.0.1:8000/docs`의 Swagger UI에서 POST 요청을 테스트할 수 있음.

## 5. PUT으로 데이터 수정하기

```python
@app.put("/games/{game_id}")
async def update_game(game_id: int, game: Game):
    if game_id not in games_db:
        raise HTTPException(
            status_code=404,
            detail="해당 게임을 찾을 수 없습니다."
        )

    games_db[game_id] = game.model_dump()
    return {
        "message": f"game id: {game_id} update success",
        "update_game": games_db[game_id]
    }
```

`game_id not in games_db`를 사용해 수정할 게임이 존재하는지 확인함.

게임이 존재하면 해당 ID의 값을 새 요청 데이터로 교체함. 게임이 없으면 `HTTPException`을 발생시켜 404 상태 코드를 응답함.

## 6. DELETE로 데이터 삭제하기

```python
@app.delete("/games/{game_id}")
async def delete_game(game_id: int):
    if game_id not in games_db:
        raise HTTPException(
            status_code=404,
            detail="해당 게임을 찾을 수 없습니다."
        )

    deleted_game = games_db.pop(game_id)
    return {
        "message": f"game id: {game_id} delete success",
        "deleted_game": deleted_game
    }
```

딕셔너리의 `pop()`은 지정한 키의 값을 삭제하면서 삭제된 값도 반환함.

삭제된 데이터를 응답에 포함하면 어떤 게임이 삭제되었는지 확인할 수 있음.

## 7. HTTPException으로 오류 응답하기

```python
raise HTTPException(
    status_code=404,
    detail="해당 게임을 찾을 수 없습니다."
)
```

- `status_code=404`: 요청한 데이터를 찾을 수 없다는 의미임.
- `detail`: 클라이언트에 전달할 오류 설명임.
- `HTTPException`은 `return`하는 것이 아니라 `raise`로 발생시켜야 함.

## 핵심 정리

1. `GET`, `POST`, `PUT`, `DELETE`를 사용해 CRUD API를 만들 수 있음.
2. `model_dump()`로 Pydantic 모델을 딕셔너리로 변환할 수 있음.
3. 딕셔너리의 `pop()`으로 데이터를 삭제하면서 삭제된 값도 가져올 수 있음.
4. 데이터가 없을 때는 `raise HTTPException(...)`으로 오류를 응답함.
