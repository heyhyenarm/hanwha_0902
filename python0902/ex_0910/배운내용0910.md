# dictionary 타입

- 키-밸류 타입

```python
myfamily = {
    "child1":{
        "name": "child1",
        "year": 2000
    },
    "child2":
    {
        "name": "child2",
        "year": 2002
    }

print(myfamily)
```

# 조건문
## if-else
```python
a = 33
b = 33
if a > b :
  print("a > b")
elif a == b :
  print("a == b")
else :
  print ("a < b")
```

## 람다

## match
C#의 switch라고 생각. 

```python
day = 2

match day:
  case 1:
    print("day1")
  case 2:
    print("day2")
  case 3:
    print("day3")
  case _:   # 기본값
    print("default")
```

```python
# or연산 활용
day = 2

match day:
  case 1 | 2 | 3 | 4 | 5:
    print("weekday")
  case 6 | 7:
    print("weekend")
```

## while문
무한루프에 빠지지 않게 주의하기. 
종료 조건을 설정하기. 

```python
i = 0

while i < 6:
  i = i+1
  print(i)

while i < 6:
  if(i == 3):
    break
  i += 1
  print(i)

while i < 6:
  print(i)
  i += 1
else:
  print("i는 6보다 같거나 크다")
```

## for문
C#의 foreach와 유사. 
for문과 같이 for-count문을 사용할 수는 있지만 잘 사용하지 않는다고 함.
대부분 for-in문 사용. 

```python
fruits = ["apple", "banana", "cherry"]
for x in fruits:
  print(x)
  if x == "banana":
    break
```

# 범위 range

# := 연산자
대입 표현식(assignment expression) 연산자.
**왈러스 연산자(walrus operator)**라고 부름.
변수에 값을 대입하면서, 그 값을 같은 표현식 안에서 사용할 수 있음.

```python
if (n := len("hello")) > 3:
    print(n)  # 5
```
